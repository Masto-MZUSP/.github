# Laboratório de Mastozoologia | MZUSP

## Pesquisa, dados e ferramentas

Esta organização reúne os recursos computacionais e metodológicos desenvolvidos pelo **Laboratório de Mastozoologia do [Museu de Zoologia da Universidade de São Paulo (MZUSP)](https://mz.usp.br/pt/laboratorios/mastozoologia/)**.

Nosso objetivo é organizar e compartilhar protocolos, códigos, scripts, tutoriais e conjuntos de dados produzidos por docentes, estudantes e colaboradores, contribuindo para a documentação e a reprodutibilidade das atividades de pesquisa e curadoria do laboratório.

### Sobre o laboratório

Nossa pesquisa parte da coleção de mamíferos do MZUSP. A partir de espécimes tombados, integramos dados genômicos, morfológicos e ecológicos para investigar a origem, a diversificação e os padrões de diversidade dos mamíferos neotropicais.
